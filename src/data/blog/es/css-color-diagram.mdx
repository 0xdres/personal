Los colores nombrados en CSS son una característica fascinante que nos permite usar nombres descriptivos como "crimson", "teal" o "lavender" en lugar de códigos hexadecimales. Este diagrama interactivo muestra todos los colores CSS nombrados organizados de forma visual.

## ¿Cómo funciona?

Este diagrama utiliza el **algoritmo de Voronoi** para crear regiones basadas en la similitud de colores. Cada región representa un color CSS nombrado, y puedes interactuar con él para ver su nombre y valor.
